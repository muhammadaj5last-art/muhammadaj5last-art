## 🚀 Featured Projects

### 🗣️ [Quran Assistant — Offline Android Voice Assistant](https://github.com/muhammadaj5last-art/QuranAssistant)
**Kotlin · Android · Jetpack Compose · sherpa-onnx · SQLite**

An Arabic-first Quran assistant with local Arabic/English speech-recognition models and an Arabic hands-free activation phrase (**يا مساعد القرآن**).

- Voice commands for Quran recitation and playback
- Searchable 114-Surah catalog
- Downloadable recitations, locally indexed for offline playback
- SQLite-based audio library metadata

**Note:** Speech recognition works offline; downloading a recitation for the first time needs an internet connection. Hands-free activation currently runs while the app is in the foreground.

### 🎮 [SaudiBoy — ESP32-S3 Arcade & Telemetry](https://github.com/muhammadaj5last-art/SaudiBoy-ESP32-Telemetry)
**Embedded C++ · ESP32-S3 · Wi-Fi · HTTP/JSON · Python**

A handheld arcade system combining four games with device observability and power-aware firmware.

- Finite-state-machine game logic and adaptive difficulty
- OLED graphics, button input, and buzzer audio
- Deep-sleep power management and battery monitoring
- Local Wi-Fi telemetry dashboard and Python CSV logger
- [Browser simulator](https://codepen.io/editor/otvpdvxe-the-sasster/pen/01a03939-5fc6-792f-ae7e-065f03083a58) for rapid experimentation

### 🍎 [Apple vs. Orange — Image Classifier](https://github.com/muhammadaj5last-art/Apple-vs.-Orange-Image-Classifier)
**Python · TensorFlow/Keras · OpenCV · NumPy**

An introductory computer-vision project using a model trained with Google's Teachable Machine, exported to Keras, and run in Python.

- Image preprocessing and color-channel conversion
- Model loading and prediction
- Simple end-to-end image-classification workflow
